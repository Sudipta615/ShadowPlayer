# Application assets

Everything in this directory is **build input**, not build output.

| Path | Source | Policy |
| --- | --- | --- |
| `icon.svg` | hand-authored | Canonical icon. Edit this, never the rasters. |
| `make-icons.sh`, `make-icon-containers.py`, `rasterizer/` | hand-written | Regenerate the rasters from `icon.svg`. |
| `icon-16.png` … `icon-1024.png`, `icon.icns`, `icon.ico` | generated by the scripts above | **Pinned in Git.** CI must be able to package a release without running an SVG rasterizer, and icon output must not change because a rasterizer dependency updated. Regenerate deliberately and commit the diff. |

`rasterizer` is a nested Cargo project used only by `make-icons.sh`. It has no
`Cargo.lock` in the repository: the root workspace lockfile is the single
authoritative lockfile (see `.gitignore`), and the rasterizer is built with
the pinned toolchain the script invokes.
